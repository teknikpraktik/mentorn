Koncept

Sunk cost

Du har lagt tre timmar på att läsa ett kapitel. Du förstår fortfarande inte. Vad gör du?

De flesta fortsätter, för att de redan lagt så mycket tid. Detta kallas sunk cost: att fortsätta bara för att du redan lagt tid på det.

Det du lagt ner är borta oavsett vad du gör nu. Det enda som spelar roll är vad som ger bäst resultat härifrån.

Fastnad i sunk cost

Fortsätter för att du lagt tid
Byter inte strategi
Kastar mer tid på fel saker
Kan göra det bra, men gör fel sak

Fri från sunk cost

Märker när något inte fungerar
Byter strategi istället för att nöta
Tänker på resultat, inte nedlagd tid
Fokuserar på att förstå
